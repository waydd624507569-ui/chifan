# 🍚 吃饭日记

一个用来记录每天吃了什么的小应用。

- **记起来快**：顶部一句话输入，回车即存；餐次按时间自动判断
- **常吃的一键记**：点一下标签就记上了，支持撤销
- **选择困难**：内置抽签，吃过越久的越容易被抽到
- **能补记**：日历里点任意一天，右上角 `+` 补记
- **看得见变化**：连续记录天数、外卖 vs 自制、花费、最常吃
- **留个影**：可以拍照或从相册选图，自动压缩存在本机，点缩略图看大图

单文件、零依赖、离线可用。数据只存在你自己的浏览器里（localStorage），不上传任何服务器。

照片单独存在 IndexedDB 里（localStorage 只有 5MB，放不下照片），记录里只存一个引用。

「设置 → 导出备份」可以导出 JSON（含照片）/ CSV，换设备时用得上。
