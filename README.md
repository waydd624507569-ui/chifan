# 🍚 吃饭日记

一个用来记录每天吃了什么的小应用。**添加到手机主屏幕后可以当 App 用，断网也能记。**

线上地址：https://waydd624507569-ui.github.io/chifan/

## 能做什么

- **记起来快**：顶部一句话输入，回车即存；餐次按时间自动判断
- **常吃的一键记**：点一下标签就记上了，支持撤销
- **选择困难**：内置抽签，吃过越久的越容易被抽到
- **能补记**：日历里点任意一天，右上角 `+` 补记
- **留个影**：拍照或从相册选图，自动压缩存在本机，点缩略图看大图
- **看得见变化**：连续记录天数、外卖 vs 自制、花费、最常吃

## 数据放在哪

全部存在**你自己的浏览器**里，不上传任何服务器。

- 记录、常吃清单 → `localStorage`
- 照片 → `IndexedDB`（localStorage 只有 5MB，放不下照片，记录里只存一个引用）

「设置 → 导出备份」可以导出 JSON（含照片）/ CSV，换设备时用得上。

## 关于这个仓库

- `index.html` —— 整个应用（单文件、零依赖、无构建步骤）
- `manifest.json` / `sw.js` / `assets/` —— PWA 相关：主屏幕图标、启动图、离线缓存
- 部署：push 到 `main` 后由 GitHub Actions（`.github/workflows/deploy.yml`）自动发布

改完代码直接提交，Actions 会自动重新部署；`sw.js` 里的 `CACHE` 版本号在改了缓存策略时才需要动。
